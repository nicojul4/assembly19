# Assembly #19

Website ini menggunakan React dan Vite.

## Menjalankan secara lokal

```sh
npm install
npm run dev
```

Buka alamat lokal yang ditampilkan Vite di terminal. Jangan membuka `index.html`
langsung atau memakai Live Server biasa karena JSX perlu diproses oleh Vite.

## Build produksi

```sh
npm run build
npm run preview
```
